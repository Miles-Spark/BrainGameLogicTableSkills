# 关卡明显错误清单

根据下面的清单逐条检查关卡策划案的逻辑图是否有错误



## 逻辑图相关错误清单

逻辑图中的节点名大多为为物品表中物品类型名+等级，一少部分为特殊关键字以及特殊关键字和物品类型组合，比如"Computer_1"是物品类型+等级也是物品名； "隐藏Computer_1"这个是关键字+物品名；"游戏胜利"这个是特殊关键字; ”动效Woman_1_Idle“这个是关键字+动效名，动效名是“Woman_1_Idle”

1.出现物品表中不存在物品名和动效名。

2.缺少游戏必要关键字 游戏胜利”。

3.操作分支最后一个动效不是是循环动效。操作分支判断参考逻辑图分支说明。

4.逻辑图关卡根节点中是否有关卡id



### 逻辑图分支说明

​	逻辑图中Level+id为关卡根层级，Level+id层级之下为关卡分支，是逻辑图中的第一层。关卡分支有操作分支和特殊分支，开始于逻辑图中的第二层。特殊分支没有操作对象是直接给操作分支调用的，之后只有一个指令层，操作分支有多种操作类型，分别是点击，双击，上下左右滑动和拖动，之后还有三个层级，前两个层级表示操作对象和类型，最后一个层级是指令层，所以特殊分支和操作分支可以通过层级数来判断。
